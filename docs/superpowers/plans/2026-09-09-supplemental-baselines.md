# 论文基线补强与补充实验实施方案

> **For agentic workers:** 使用 superpowers:executing-plans 逐项执行；每项以证据验收，不因批次边界重新索要授权。

**Goal:** 补齐可信外部基线、公平比较、独立验证和成本证据，使论文结论与证据强度相匹配。

**Architecture:** 保留当前冻结研究 E0；新增独立补充研究 E1–E4，单独绑定代码、数据、角色和统计计划。先完成来源与实现核验，再冻结补充协议、运行开发试验和正式计算；所有方法共享可复用预测，但不复用已消费终局数据。

**Tech Stack:** Python、PyTorch、现有组级 CRC/回执接口、公开论文与固定提交的作者源码；新增实现放在 `research/supplemental/`，与冻结目录隔离。

**Spec:** [用户已批准的基线审计](../../reports/progressive-baseline-acceptance-review.md)。2026-09-09 用户明确授权“按照这个思路修改实施方案，该补充实验补充”。本文件替代旧计划中“当前计算结束后再决定是否补充”的执行顺序；必要补充实验已进入范围。

### 优于哪些方法，以及“优于”的准确含义

| 对照对象 | 在匹配条件下获胜所支持的结论 | 不支持的扩张表述 |
|---|---|---|
| K5采样方差 | 融合评分比仅使用随机采样分歧更有效地筛选可接受区域 | 优于独立训练的Deep Ensembles；证明生成后验正确 |
| LR重投影残差 | 不确定性/纹理信息在LR一致性之外提供了有用增量 | 低LR残差能排除全部虚构细节；全面优于OpenSR-Test |
| Adame等NeurIPS 2025论文公式RGBN适配 | 同模型、样本预算、数据、风险和合理开发搜索下，本评分获得更高可信覆盖 | 完整复现并超越原论文全部实验/理论 |
| 同论文固定版本released-helper RGBN适配 | 对另一明确实现路径的覆盖改进，且差异可复查 | 作者所有公开实现相同或原论文结果错误 |
| im2im-UQ（ICML 2022）固定中心适配 | 相对独立学习式不确定性路线，在共同掩码任务上的覆盖/成本取舍更好 | 用掩码覆盖直接压过原生区间覆盖；全面超过ICML论文 |
| 自身fusion、spatial、beta等消融 | 判断哪些组件对观察到的增益有贡献 | 多个消融等于多个已发表强基线；单凭获选beta证明因果机制 |

本研究主要固定超分图像，再判断哪些区域可接受。即便上述评分比较全部获胜，
也不能据此声称重建质量超过SinSR、LDSR-S2或其他生成模型。若比较改变了中心
预测，须归入完整系统比较，并单列重建质量，不能将全部收益归因于评分。

### 量化目标与判定规则

- **风险前提：** “同风险下覆盖优于”要求双方通过预先规定的风险资格检查。
  E0目标仍为组风险上界≤0.05，规则完全不变；补充研究沿用0.05风险目标，
  在自身协议中冻结置信分配与计算方式，校准满足CRC不自动等于终局风险认证通过。
- **统计优势：** 预设的配对覆盖差下置信界>0，才宣称对相应基线有统计支持的增益。
  E1/E2的三个主要外部比较为full对paper-moment、released-helper、im2im适配，
  按Task 3的比较族规划冻结；K5/LR和消融默认描述性，若要增加确认性声明须在
  补充协议冻结前分配比较预算。不能用单个未校正显著结果代表全部方法。
- **实际意义：** E0保留原定增益下界≥0.05，即至少5个百分点的工程目标。
  E1/E2将同样的5个百分点作为预期工程目标，并在补充协议中明确固定；
  仅点估计达到5个百分点而下界未达到时，只能报告点估计，不能说该目标已获证实。
  下界>0但<0.05可支持正增益，不能升级为达到工程目标。
- **复核收益：** 逐方法报告固定32×32整块复核数量/比例、配对变化和统计不确定性。
  如需确认性“复核量下降”声明，补充协议须提前另行分配统计预算；目前该项是
  次要描述性终点，不消耗或挪用已规划的主要风险/覆盖比较预算。
- **效率替代目标：** 若提出“效果相近但成本更低”，须在新研究冻结前设定非劣效
  界、对应检验和成本比较条件；本方案没有将未显著差异自动定义成相近，也没有
  授权在看到测试结果后改用非劣效标准挽救结论。
- **泛化边界：** 对每个所评估地域分别说明样本量和风险证据；单域阳性不能代表
  跨域成立。小规模SPOT观察不能代替足够独立组的风险验证，不宣称所有地区有效。

风险与覆盖界的样本量可行性按Task 3先行核算；上述目标不构成无论成本都必须
取得阳性结果的要求。无法达到证据精度时，提交精度评估和真实结果，并收窄声明。

### 预期论文结论及收窄路径

只有各项证据支持时，目标结论才可写为：

> 在所评估的遥感超分场景中，相比采样方差、重投影一致性及已发表不确定性方法
> 的明确适配，本方法在满足预设风险上界的条件下提高自动接受覆盖率，减少整块
> 复核工作量；独立地域实验支持其在这些地域的可迁移性，并量化了相应计算成本。

如果仅超过简单基线，则结论限于比简单评分更有效；若仅局部场景有效，则明确
适用场景；若风险证据不足，则不宣称风险合格覆盖优势；如果结果无优势，则完整
报告边界与失败原因。没有真实人工计时，不写“人工效率提升多少倍”。论文录用、
全领域SOTA、首次共形掩码或新统计理论均不是这套实验能够自动保证的结论。

- [ ] 按地理组数计算证据精度，冻结样本量和声明范围。以6方法、3个full对外部方法比较为规划上限：风险delta=.025/6、增益delta=.025/3；组损失[0,1]，配对覆盖差[-1,1]。

规划计算：风险Hoeffding半径 `sqrt(log(6/.025)/(2*n))`；配对增益半径 `sqrt(2*log(3/.025)/n)`。
风险半径≤.03需3045组，≤.02需6851组；增益半径≤.05需3830组，≤.02需23938组。
