# 论文基线补强与补充实验实施方案

> **For agentic workers:** 使用 superpowers:executing-plans 逐项执行；每项以证据验收，不因批次边界重新索要授权。

**Goal:** 补齐可信外部基线、公平比较、独立验证和成本证据，使论文结论与证据强度相匹配。

**Architecture:** 保留当前冻结研究 E0；新增独立补充研究 E1–E4，单独绑定代码、数据、角色和统计计划。先完成来源与实现核验，再冻结补充协议、运行开发试验和正式计算；所有方法共享可复用预测，但不复用已消费终局数据。

**Tech Stack:** Python、PyTorch、现有组级 CRC/回执接口、公开论文与固定提交的作者源码；新增实现放在 `research/supplemental/`，与冻结目录隔离。

**Spec:** [用户已批准的基线审计](../../reports/progressive-baseline-acceptance-review.md)。2026-09-09 用户明确授权“按照这个思路修改实施方案，该补充实验补充”。本文件替代旧计划中“当前计算结束后再决定是否补充”的执行顺序；必要补充实验已进入范围。

## 全局约束

- E0 继续至完成，保留8方法、full−w3主比较、原风险界、角色和终局规则；不改 `research/trustmask/`、`src/trustsr/` 或其冻结协议。
- 不把改动后的公式/适配称为官方完整复现，不把内部消融计作外部方法数量。
- 公共论文/开源发布来源足够；不要求逐成员实际卫星源映射，不联系作者或申请账户作为常规前置条件。
- 来源证明与数据隔离是两件事。训练、开发、校准、测试按地理组隔离；同源影像及邻近区域检查用于防泄漏，不升级为来源许可门槛。
- 不访问旧 A/B/C、已消费 Spain 终局像素/缓存；E0 全部角色均不得作为“全新独立数据”再次命名。
- 不读 E0 测试结果来选择补充基线、超参数、指标或样本量。新增研究未冻结前不访问其测试输出。
- 新增任务实行单独回执、断点续跑、失败记录、顺序写入；已授权连续运行，不能在正常批次结束时等待人工确认。
- 本方案是执行设计，不是已冻结的数据协议或实验完成证明。没有数据清单、代码校验和及角色清单时禁止正式 GPU 批量执行；可继续源码、元数据和 CPU 准备。

## Task 3：数据清单与统计可行性先行

**Files:** 后续 `research/supplemental/data_inventory.py`、`research/protocols/trustmask-supplemental-v1.json`、`tests/research/test_supplemental_protocol.py`；本地受控数据清单不入Git。

- [ ] 先读取公共发布元数据，锁定版本、对象大小/校验值、RGBN与×4支持、空间信息和许可证；不先下载全体像素试排名。
- [ ] 从既有数据角色清单和历史使用记录排除重复/相关地理组。当前SEN2NAIPv2 crosssensor的8000成员已被现有/历史研究覆盖，不能从中虚构新的独立留出集。
- [ ] 新增训练角色；开发、正式校准、终局测试完全分离。开发数据可有明确披露的既有开发来源，但旧终局不转训练，新主测试必须真正独立。
- [ ] 优先核验未使用的公开RGBN×4源。OpenSR-Test SPOT公开说明为9张，只列跨传感器描述性候选；其NAIP可能重叠且尺寸484，不能直接冒充512支持；Venus×2不直接加入×4主表；已用Spain不重开。

公开规模与波段依据：[OpenSR-Test作者数据卡](https://huggingface.co/datasets/isp-uv-es/opensr-test)。该页面只支持候选筛查，正式数据身份仍须固定不可变版本。

- [ ] 按地理组数计算证据精度，冻结样本量和声明范围。以6方法、3个full对外部方法比较为规划上限：风险delta=.025/6、增益delta=.025/3；组损失[0,1]，配对覆盖差[-1,1]。

规划计算：风险Hoeffding半径 `sqrt(log(6/.025)/(2*n))`；配对增益半径 `sqrt(2*log(3/.025)/n)`。
风险半径≤.03需3045组，≤.02需6851组；增益半径≤.05需3830组，≤.02需23938组。
这些是界宽度计算，不是功效保证或已批准必须收集的样本数。小样本不得靠像素数充当独立组数。
风险目标保持.05；正式新协议必须提前选择有足够安全余量的开发/校准目标并论证，不能看结果后降门槛。

- [ ] 清单达不到所需精度时，记录可达到的界与结论范围；继续找适配公开源或将外部研究明确降为描述性，不宣称已补齐大样本证据。
- [ ] 新协议记录确切方法族、全部配置、比较分配、样本角色、损失、空掩码约定、冻结时间、代码和权重hash；任何必填项缺失都拒绝正式启动。

验收：已消费终局/重复组、缺hash、训练访问测试、未冻结模型访问测试、同数据另换名字均触发拒绝；元数据拒绝原因可追溯。
