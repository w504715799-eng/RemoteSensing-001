## 数据合同与未决条件

固定 HF 提交不变，候选包改为 **v2／100**，与公开 CSV 同版本；具体路径、SHA 见审计补充。
此决定发生在任何 Spain 图像访问前，未改变主比较、样本范围或根据模型效果筛选数据。
版本化数据卡已确认 L2A 的 RGBN 索引 `[3,2,1,7]`、HR RGBN 顺序、×4、512×512
HR，以及 `HRharm` 相对 L2A 的协调关系。输出意向仍为 [0,1] 反射率。
不得直接把 SPOT 的除以 10000、clamp、HR 字段名当成 Spain 已确认合同。
官方用例展示除以 10000，但 Spain 包特定的 dtype／nodata／异常范围约定仍未完整核实。
不再要求解释 100→021 内容差异；最终入口必须核验同版本包的嵌入 metadata 与固定清单，
通过后才能按 metadata 行定位图像；不允许假定字典序就是张量顺序。
缺失处理、异常范围／nodata 与解包安全合同尚待完成，属于冻结阻碍，不是默认值。
原 SPOT-only loader 保持不变；新入口单独实现，先用合成数据检验。

## 缺失、停止与展示

成员在像素访问前冻结。只允许按身份、数据合同、文件完整性和非有限值规则拒收；
不按误差或质量分数过滤。主比较按完整配对，逐方法报告有效／计划分母及原因。
若无法形成任何有效配对，该子集标为无法评估，不补入有利样本。
身份或数据合同不一致时停止整批，不自动换版本、改归一化或删除指标。
运行失败只补同身份的缺失计算；不依据中途结果扩样或换方法。
展示每子集按冻结 ROI ID 字典序最前两项；失败则保留失败格，不用其他 ROI 替代。

结构诊断目前限定为图像级探索性结果：默认 softmin 分量均值，不命名为硬幻觉像素比例。
16 像素裁边及 SR 配准后的地图不与原始评分逐像素对应。不新增像素级幻觉检测主张。
最终是否保留仍须完成有效值／配准失败规则与合成验证；详见 OpenSR 合同报告。
元数据中官方质量字段的有限暴露必须在最终协议及论文复现说明中披露。
