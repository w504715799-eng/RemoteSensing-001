## 目标与范围

在不训练新模型的前提下，完成一篇关于 Sentinel-2 RGBN ×4 超分辨率不确定性评分的
成本、误差尺度和校准迁移的实证研究论文。保留现有 inconclusive 结果，新增最近邻
文献基线和一次冻结的 Spain 外部评估。暂按 4–6 周成稿准备安排。

第一篇必须完成：公平评分比较、R9/R1 定义解释、成本、独立外部描述与原内部结果报告。
从必做范围移出：新主干训练、复合风险函数、分组／加权共形、SEN2NEON 接入、GeoSR
下游分割、全量回退产品、三套完整随机种子实验。K5 内五个种子不能冒称五次独立研究
复现；已有 K5/K25 四 ROI 检查只能作为有限的采样稳定性证据。

## M2：限定开发与计算预算

- [ ] 先核验 development 允许复用的资产范围；不为查缓存连接受保护的 B/C 状态。
- [ ] 在允许的 development 数据上完成一个邻域基线配置，避免大规模参数搜索。
- [ ] 若 development 缓存不可用，先重估成本，不悄悄重跑历史阶段。
- [ ] 固定同一中心重建和 K5 seeds，五种评分共享预测；不为每种评分单独推理。
- [ ] 只在 SPOT／合成数据上测试新入口及性能，再冻结外部执行配置。
- [ ] 在预定一批开发运行上记录 GPU 时间、峰值显存、CPU 指标时间与缓存命中率。
- [ ] 在开发选择结束后提交最终协议：方法、模型、种子、输入处理、样本／空间组、
      主次指标、区间与多重比较规则、缺失处理、成本预算和展示规则全部绑定同一版本。

若最终是 48 张完整 Spain 图像，主要新增工作约为 **240 次 LDSR 图像推理 + 48 次
SEN2SRLite 推理 + bicubic 与 CPU 后处理**。邻域评分复用同一批 K5。此数量按单图模型
调用计，不是扩散步数，也不等于 GPU 小时；若模型入口需切块则另外记录实际次数。

设开发测得单图 LDSR 时间为 `tL` 秒、SEN2SRLite 为 `tS` 秒，则粗略预算为：

```text
GPU小时 ≈ (240*tL + 48*tS)/3600 + 实测加载/传输/写缓存开销
费用 = 供应商当前小时价 × 实际计费小时
```

预算不足时优先删除可选扩展，不因外部指标好坏缩减样本或增跑采样。一个 worker
作为默认；已有四 worker 基准未显示端到端加速，不重复做该优化。

## 可选增强不进入当前执行清单

默认不做回退。只有用户另行选择扩展、且外部结果尚未打开，才可在协议冻结前加入**固定规则的保守
回退**，用于完整图像的效用诊断。必须有全 bicubic、原 LDSR、随机同预算回退和评分
回退对照，同时报告遗漏／合成损失。掩膜风险保证不能转移为回退后整幅图像保证。

预算或时间紧张时不加入。分组共形、SEN2NEON 与下游分割留作第二篇的独立研究方向。
