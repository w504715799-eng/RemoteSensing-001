## 执行证据

部署本地提交 `07103bf` 的 Git archive 到独立持久化目录，逐文件核对 **372** 个源码／
文本文档哈希。原 base 为 Python 3.12.13、AMD EPYC 7K62；CPU capability=AVX2、
interop=192，原进程 intraop=96。所有本次子命令隐藏 CUDA，测量内使用单线程。

固定脚本 `python -m scripts.paper.benchmark_external_cpu` 只生成一个完整512网格
合成样本及七份合成预测，执行解码→缓存→五评分→真实 OpenSR→汇总，两轮科学结果
逐字节一致，结构诊断有效。原脚本 scope 中的“synthetic-local-cpu-only”是合成／本机
执行标签；本次执行地点为已核验的云端，仍不是 Spain 结果或完整计费基准。

|---|---:|

小型路径无关证据：[cloud-cpu-execution-v1.json](../../paper/tables/cloud-cpu-execution-v1.json)，
