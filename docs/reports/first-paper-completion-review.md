## 方法修订

| 审阅发现 | 修订与依据 |
|---|---|
| 评分定义不够具体 | 正文 3.2 定义 area LR 残差、总体三模型／K5 方差、联合邻域二阶矩和 Gaussian 参数；对照 proxies.py、local.py、neighborhood.py |
| 邻域评分容易被误解 | 明确含空间纹理，即使种子预测相同也可非零；不是仅平滑 K5，讨论中保留归因未分离的局限 |
| 单位混淆 | 区分反射率与反射率平方尺度；覆盖、rho 和 softmin 为无量纲 |
| 成本口径混淆 | 区分独立部署 1／3／5 次与共享研究每 ROI 7 槽；bicubic 为基线输出计算；不给普遍成本最优结论 |
| 阈值规则不完整 | 补最大可行已观测阈值、score ≤ t、无可行候选全拒绝；区分 alpha、confidence_error 和数值阈值 |
| 模型与结构设置不完整 | 补种子中心、采样配置、线程与版本、OpenSR 固定参数；说明辅助协调不改变主风险 |
| R9 操作顺序不明确 | 明确完整网格先绝对误差再均值池化，之后应用保留掩码 |

正文标题改用 Threshold Transfer；研究问题限定为可测调用／时间与排序增益，
不以未定义的下游效用判定额外采样“值得”。保留 Crops R1 和两子集 R1 rho 的不利比较。
