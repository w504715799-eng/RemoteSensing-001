# 递进可信覆盖：文献、创新边界与投稿证据审计

审计日期：2026-09-09。只读研究设计、`research/trustmask/scores.py`、
`pipeline.py`、`paper/related-work.md` 和公开文献；未访问新 calibration/test
结果或像素，未改代码、冻结协议或运行任务。本文是定位审计，不是实验结论。

## 1. 当前可以成立的定位

**目前最可信的贡献候选是：在固定 Sentinel-2 生成式重建上，检验可解释的分数
组合能否在相同风险目标下增加自动通过覆盖，并降低复核工作量。** 这属于应用方法
与严格实证研究；当前不足以称新共形理论、新后验估计器或已验证的跨域通用方法。

当前候选为
`F = λ q_a(LR) + (1−λ) q_d(G(U+βT))`，其中
`U=B3(mean_band Var_5(S))`，`T=mean_band[B3(μ²)−B3(μ)²]`，
`μ=mean_5(S)`，`q_a(x)=x/(x+a)`。
代码先分别计算 `G(U)`、`G(T)`，再线性组合，与上述式子一致。
β∈{0,0.5,1}、λ∈{0,0.25,0.5,0.75,1}；尺度仅由 scale-fit 拟合。
中心 seed 3407、RGBN、×4、R9、五次采样固定。主风险是等权地理组、再等权
ROI 的“ROI 内最大保留 R9”期望≤0.05，并非每个像素有95%正确概率。

新样本框为7,477成员、6,158地理组；这些是全体角色合计，不能写成6,158个
独立终局测试组。五角色为尺度拟合、开发校准、开发验证、正式校准、终局测试。
组间隔离是操作事实，组独立/可交换仍是条件。此前已存在成熟的旧 Spain 研究，
不能将项目描述为“没有真实实验”；但旧研究及已见结果不构成此新候选方法的独立
外部验证，旧测试保持封闭。

## 2. 最直接的先行工作

**Adame、Csillag、Goedert，NeurIPS 2025。** 正式会议身份可由
[会议页面](https://neurips.cc/virtual/2025/poster/117061)确认，不应只写成未发表预印本。
[原文v3 §2.1–2.3](https://arxiv.org/html/2502.09664v3)已经提出黑盒生成式SR、
多样本方差、邻域二阶矩加Gaussian平滑，以及控制保留区最大局部误差期望的二值
掩码。故“生成式SR+方差+空间平滑+CRC可信掩码”整体并非本项目首创。
其主要实验使用SinSR、Liu4K、Lab；本文改为LDSR-S2、跨传感器RGBN及组级统计。
其邻域误差先平滑图像再比较；本文先取波段平均绝对误差再平滑。R9、数值上限、
统计单位和阈值不能直接搬用。这是**最应直接比较**的先行方法。

作者[固定提交中的calculate_mask](https://github.com/adamesalles/experiments-conformal-superres/blob/819086a9e21077010bdcee233373a25c8d32bdd0/src/masks/generate_masks.py)
在一次迭代时，先求每个样本的空间方差再跨样本平均；原文公式则先跨样本聚合
二阶矩。两者一般不等。主入口另存普通跨样本像素方差。本文w3应保持
“paper-formula RGBN adaptation”标签，不能称作者代码的完整复现；上述核对只
覆盖此提交此函数，不证明作者所有实验有误，也不能把实现差异算成本项目创新。

**Horwitz、Hoshen，Conffusion（2022）。**
[原文](https://arxiv.org/html/2211.09795)以分位数回归微调扩散网络，预测区间上下界，
再用风险控制校准；同时讨论采样区间基线。
[官方代码](https://github.com/eliahuhorwitz/Conffusion)公开。这否定“扩散SR首次具有
统计不确定性”的宽泛表述。它输出区间且需要训练，当前输出固定中心上的拒绝掩码；
区间覆盖率、区间宽度与保留区R9风险、保留覆盖不同，不能拿文献中的数字作主表
同量纲比较。若未来用其区间宽度作分数，必须同中心、同数据、重新按本项目损失
校准，并明确是适配；本审计不要求或启动新的GPU训练。

**Zheng、Dewil、Arias，2026。** 已读取
[完整原文v1，包括方法、最优性推导、实验与附录](https://arxiv.org/html/2603.14074v1)。
它为多帧卫星SR提出自监督Gaussian NLL，估计后验均值和逐像素方差；在相应
噪声、随机子采样等条件下论证最优性。实验为SkySat L1B衍生的合成×2数据，
Gaussian区间覆盖是经验诊断，不是本文CRC保证。
[arXiv记录](https://arxiv.org/abs/2603.14074)目前为2026-03-14 v1，备注
“Conference submission”；本次精确标题及编号检索未确认正式接收或官方代码。
只能写“预印本；代码未核实”，不能写“没有代码”或猜测接收会议。它与本文任务
邻近，尚非可直接替换的单幅RGBN×4评分基线；但足以要求撤回“卫星SR首次无需
HR估计不确定性”的表述。本文只是部署评分无需HR，开发、校准和验证仍需参考。

此外，[Angelopoulos等，ICML 2022](https://proceedings.mlr.press/v162/angelopoulos22a.html)
已研究图像回归的分布无关区间；
[Teneggi等，ICML 2023](https://proceedings.mlr.press/v202/teneggi23a.html)的K-RCPS
研究扩散输出的多维风险控制与区间长度优化。两者使“首次将效率目标与风险校准
结合”也不可成立。[CRC原文](https://arxiv.org/abs/2208.02814)控制单调损失的期望；
其校准随机性上的边际结论，应与固定部署阈值的终局单侧风险证据分开。

## 3. 逐项声明矩阵

| 拟议声明 | 已继承内容 | 潜在增量 | 当前缺口/允许写法 |
|---|---|---|---|
| 黑盒生成式SR可信掩码 | Adame的掩码与CRC框架 | RGBN、固定中心、组级目标的适配 | 写“adapt/evaluate”，不写首次 |
| 邻域二阶矩评分 | Adame的空间方差公式及平滑 | β控制纹理项相对强度 | β=1基本回到继承分数；需证实β选择有效 |
| U与T分解 | 联合方差的代数恒等式 | 揭示既有分数混合采样分歧和均值纹理 | 不是新定理；T不自动等于伪不确定性 |
| LR与不确定性融合 | 重投影一致性及常见标量融合 | 特定固定尺度、有限候选族的任务适配 | 需独立证实互补；不是新后验或误差概率 |
| 更高可信覆盖 | 既有风险约束下选阈值 | 相同α、计算和校准资源下的覆盖差 | 目前是待检验主假设，不能把开发最优当终局收益 |
| 组级校准及五角色 | 样本拆分与有界风险控制原则 | 明确遥感总体和可复查的泄漏防护 | 严谨设计是价值，不等于新统计理论 |
| 自动通过减少人工 | 选择性接受/拒绝的应用范式 | 32×32复核单元与碎片化成本量化 | 未计时只能称工作量代理；像素减少不保证人工减少 |
| 跨域有效 | 旧Spain研究与公共数据资源 | 新方法在独立目标域的再校准/直接迁移评估 | 当前新方法尚未独立外部验证，旧结果不能补位 |

**“只是调了已有方差”这一质疑有实质依据。** β直接调节继承分数的纹理权重，
λ是标量融合；没有新模型训练目标或新保证。严格递增q在单一分量上不改变排序，
因此单独归一化不是新的排序能力；但固定101点阈值网格会使归一尺度影响可选
掩码，融合又会改变相对贡献。这是审稿应考虑的数值/搜索因素，不能把所有收益
都解释成物理机制。full的15配置含λ=1时三个重复LR配置；实际不同分数至多13个。
不同家族候选数不同，应透明报告，不能笼统声称候选数量完全相等。

可检验机制有三条：LR残差能否暴露低采样方差的共同偏差；降低T权重能否避免
正确纹理被过度拒绝；空间平滑能否减少掩码碎片而不漏放结构误差。这些都是假设。
反例也应明确：满足退化算子的错误高频可有低LR残差；模式坍缩可有低采样方差；
真实边缘和错误细节都可有高T。五次随机采样既不证明后验正确，也不将U识别为
纯epistemic或aleatoric不确定性。

## 4. 最强审稿威胁及最低发表证据

1. **方法增量太小。** 最低要求是完整方法对w3的预设配对组覆盖差及区间，同时
   两者满足同一风险证据标准；保留LR、K5、fusion、spatial、beta0、beta1全部
   比较及失败。正收益若只出现在开发集、仅优于弱基线，或完整方法退化为LR，
   不足以支持三组件原创叙事。可据终局结果诚实缩为比较研究，不能反向换主比较。
2. **共同偏差与参考误差。** 跨传感器参考受配准、时间和光谱差异影响；掩码可能
   识别这些差异而非生成幻觉。需明确参考风险定义，并在既定边界内给出结构诊断
   和失败案例，避免把低R9直接写成地物真实性。额外机制分层若未预注册，只能
   作为清楚标记的探索分析；本报告不改当前正在运行的协议。
3. **伪独立与外部有效性。** 完整报告各角色成员/组数、分组规则、排除摘要及
   共享S2来源/预训练重叠未完全核实的限制。不能以公开出处或地理分组证明独立。
   最低主结论限定当前总体；若宣称跨域普适，须另有新方法的独立外部数据证据。
   原阈值迁移与目标域重新校准分别报告，不能混成一个跨域成功率。
4. **统计保证被夸大。** 报告CRC规则、损失上界、全拒绝约定、固定评分及阈值
   的身份摘要、一次性终局纪律；按冻结delta分配报告各方法风险上界和主收益
   区间。风险上界合格不等于覆盖差显著。0、2、5个百分点分别解释，5个百分点
   是预设工程目标而非已有用户价值测量；不合格/证据不足必须保留。
5. **作业收益没有落地。** 并列自动通过/高误差通过像素、全拒绝ROI、32×32复核
   单元及推理/后处理时间。碎片化使复核单元不降时，不能宣称人工节省。无真实
   计时只可报告代理量与明确假设的盈亏平衡时间。无有效像素面积依据不填面积。

最低可投稿材料因此是：可重现冻结协议与代码身份、完整直接基线和消融主表、
合规风险证据及配对增益区间、失败与局限、作业代理分析，以及不超过证据的摘要。
若结果阴性，严谨可复现的适配研究仍有报告价值，但不自动达到期刊录用门槛。
本审计不读取结果来决定这些要求，也不批准重新打开测试或增开付费GPU。

## 5. 投稿定位与检索范围

若主比较和应用收益成立，优先考虑应用遥感方向的完整实证论文；例如
[IEEE J-STARS的官方范围](https://www.grss-ieee.org/publications/journal-of-selected-topics-in-applied-earth-observations-and-remote-sensing/)
与此类遥感技术应用相符，但仍要求新的且显著的技术内容。此处是基于范围的
审计判断，不是易录用推荐或录用保证。若只能证明小幅单域增量，更适宜先形成
聚焦比较/技术报告，再依据实际证据选择短文或专题渠道。当前不宜以新的通用
不确定性理论竞争顶级机器学习方法论文；也不应为了匹配刊物追认新假设。

检索覆盖：上述指定论文精确标题、arXiv编号、NeurIPS官方会议记录、作者GitHub，
以及相关工作链中的ICML图像区间与K-RCPS、CRC原文和J-STARS范围。关键查询
包括“Self-Supervised Uncertainty Estimation For Super-Resolution of Satellite
Images code publication”、“2603.14074 github”和Conffusion标题。
引用依据仅用作者原文/代码、正式会议或出版机构页面；搜索中出现的转载和聚合页
未作证据。2026工作正文与附录已核对；代码未确认是有限检索结论，不是不存在
证明。本次不是系统综述，也未穷尽截至2026-09-09所有遥感不确定性/选择性预测方法。

待解除的核心证据缺口：新方法终局收益、机制区分、实际复核收益、独立外部有效性。
这些不能通过增加措辞强度、完善工程实现或引用旧Spain结果消除。
