# 基线是否足以支撑论文：复核结论

日期：2026-09-09。本文只复核文献、已有源代码审计与实验设计；没有读取终局结果，
没有新增实验或改动冻结协议。判断属于本项目的研究建议，不是会议的统一要求。

## 判断

当前基线有合理来源，但尚不足以支撑“优于已有完整方法”的结论。
正式发表、任务匹配、实现忠实、公平预算与独立验证应同时考虑。
会议录用能证明工作经过同行评审，不能证明其已成为所有人公认的标准基线。
本次没有核验引用量或广泛复用程度，不以这些理由宣称社区共识。

| 对照 | 可信依据与适用性 | 本项目应如何定位 |
|---|---|---|
| Adame 等，NeurIPS 2025 | 黑盒生成式超分、可信掩码与局部风险控制，任务最接近；[正式会议记录](https://neurips.cc/virtual/2025/poster/117061)、[作者代码](https://github.com/adamesalles/experiments-conformal-superres)可查 | 必须优先比较。当前 w3 仅是其论文评分公式的 RGBN 适配，完整方法复现尚未成立 |
| Angelopoulos 等，ICML 2022，im2im-UQ | 图像回归区间不确定性；[正式论文](https://proceedings.mlr.press/v162/angelopoulos22a.html)、[作者实现](https://github.com/aangelopoulos/im2im-uq)公开 | 优先审查的独立方法候选。输出区间与当前二值掩码不同，不能直接搬用论文数字；接入条件和实现仍待核验 |
| Teneggi 等，ICML 2023，K-RCPS | [正式论文](https://proceedings.mlr.press/v202/teneggi23a.html)研究扩散输出区间、风险控制与区间长度优化 | 有依据的另一候选，但原实验是去噪，非本项目同任务基线；应先判断适配是否保持方法含义 |
| K5、LR 残差 | 简单可解释参照，可检验复杂方法是否值得 | 保留；不能包装成独立训练的 Deep Ensembles 或完整 OpenSR-Test 方法 |
| fusion、spatial、beta0、beta1 | 本项目的组成部分与参数限制 | 内部消融；8 个方法不等于8种已发表强基线 |

## 最重要的公平性缺口

1. **论文公式与公开 helper 不等价。** 已有[逐项审计](progressive-official-baseline-audit.md)
   发现二阶矩聚合顺序不同，窗口、平滑、颜色空间、误差和校准流程也有差异。
   不能只把当前 w3 标成原论文名字，也不能据此断言原论文结果错误。
2. **固定 w3 对比经过选择的 full，可能混入调参收益。** 当前 full 有15个候选配置，
   w3固定配置。当前比较仍有明确定义，但补充研究应给外部方法合理的开发集调参预算，
   包括论文建议的窗口和平滑选择；报告搜索空间、次数和成本，不在测试集挑弱对手。
3. **共同 CRC 只隔离评分贡献。** 将不同评分放入同一校准器适合验证评分改进，
   无法单独证明原方法的完整系统被超越。需要另行报告忠实复现或逐项披露的完整适配。
4. **区间覆盖率不等于可信像素覆盖率。** 若把 im2im-UQ 等区间宽度转成排序分数，
   需要共同中心预测、同损失与重新校准；原区间保证不能直接转成 R9 掩码保证。
   若方法必须改变重建模型，应单列完整系统比较，不能把变化全归因于评分。
5. **成本必须完整。** 同采样数和同数据预算的比较之外，还应披露各方法训练、
   开发选择、校准、部署耗时与显存。共享预测的边际成本和独立运行总成本分别报告。

## 发表证据的补齐顺序

这是本项目建议的证据门槛，不代表补齐后必然录用。

1. 完成当前冻结研究，按原来的8方法、主比较和统计门槛报告结果，包括阴性结果。
2. 单独预注册补充研究：同时覆盖最近论文的公式适配和固定版本 helper 适配，
   以同数据、模型、风险、开发预算比较；对原生设定另列复现或敏感性验证。
3. 完成至少一种独立已发表方法的适配可行性核验，优先 im2im-UQ；仅当输出、
   数据需求与比较目标一致时进入补充主表。不能为凑数量加入失去原方法含义的对照。
4. 在独立地域或数据集上验证新方法，报告同风险下覆盖增益的区间、复核单元数量与
   全流程成本。没有人工计时实验时，只声称复核工作量代理下降。

第2至4项尚未完成。补充研究不能向当前冻结比较族临时加方法，也不能依赖当前
终局表现挑选参数。现有紧凑回执不保留完整预测和分数图，不能假定可免费回放所有
新基线；所需数据、额外 GPU 计算和缓存规则需在补充协议中明确。

## 相关文献表述修正

Kutiel 等的 [What's Behind the Mask](https://arxiv.org/abs/2211.15211)
原文明确声称共形校准保证，不能概括为“没有提出保证”。后续论文对其校准推导的
质疑属于另外的理论问题，应准确区分原作者声明与后续批评；本次未独立裁定证明。
也不把这个 arXiv 页面自动认定为某个正式会议版本。

即使 full 显著超过当前 w3，也只能先证明预设场景中的适配评分增量。
研究价值仍需由机制、稳健性、独立验证和实际收益共同支持，不能由基线的会议名称代替。
