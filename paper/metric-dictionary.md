# 指标字典

状态：2026-09-08，根据冻结代码、A/B/C 和 Spain 科学 JSON 核对。所有风险使用归一化 RGBN
反射率；不是百分制，也不是分类错误概率。旧科学文件不作修改。

| 名称 | 定义和方向 | 限制 |
|---|---|---|
| R1 | 四波段绝对误差的均值，越低越好 | 中心预测与协调后的 HR 比较，不是真实地表无误差标签 |
| R9 | 对完整 R1 作反射填充的 9×9 均值池化，之后才应用保留掩码 | **先取绝对值再平均**，不同于两图分别平均后相减；2.5 m 输出上窗口宽 22.5 m |
| LR 残差分数 | 中心预测 area 下采样四倍，与 LR 的 RGBN 绝对差均值，再重复成 4×4 块 | 固定降采样一致性代理，不是 HR 误差或标定传感器模型 |
| 三模型分歧 | 中心 LDSR、bicubic、SEN2SRLite 的逐波段总体方差（除以 3），再平均 RGBN | 异构模型差异不等于随机采样不确定性 |
| 邻域方差分数 | 先对样本均方与样本均值作邻域均值，再二阶矩减均值平方，波段平均后 Gaussian 平滑；公式见正文 3.2 | 含空间纹理，非仅平滑 K5；外部固定 w=3、sigma=1、7×7 Gaussian、反射边界 |
| K5 方差分数 | 五个预测逐像素、逐波段总体方差（除以 K），再平均四波段 | 分数高表示更不确定；五个种子不等于五次独立研究 |
| 选择风险 r(c) | 分数升序，保留 ceil(cN) 个像素，其 R1 或 R9 的均值 | 同分按展平索引排序；不是 ROI 最大损失 |
| 十点离散 AURC | mean(r(0.1), …, r(1.0))，越低越好 | 不是连续积分或梯形积分；先逐 ROI 计算再等权平均 |
| 随机解析 AURC | 全 ROI 风险均值，即独立随机排序的期望 | 不需要随机模拟；不能据此声称显著优于随机 |
| AURC gain | 随机解析 AURC − 方法 AURC，越高越好 | development 上的增益带选择偏差 |
| Spearman rho | 分数与风险的平均秩相关，越高越好；常数情形代码记 0 | 排序能力不是概率校准 |
| 高风险排除比例 | 1 − 被保留的高风险像素数 / 高风险像素总数 | 高风险为风险最高 ceil(0.1N)，保留为分数最低 ceil(0.8N) |
| ROI 损失 L(t) | 分数 ≤ 阈值的保留区域内最大 R9；全拒绝时为 0 | B/C 对 ROI 损失求均值，不等于对所有保留像素求均值 |
| 覆盖率 | 保留像素数 / 总像素数 | 同时报告全拒绝 ROI；不同 ROI 大小时像素加权与 ROI 等权不等价 |
| B 校准 risk_bound | (sum(L_i(t)) + 1)/(n+1) | 校准选择准则，不是 C 的单侧置信上界 |
| C risk_ucb | 已冻结的单侧 diversified-grid-Kelly 上界 | 仅引用已发布值；不重开测试，不声称跨域成立 |
| OpenSR ha/om/im | OpenSR-Test 1.3.3、温度 0.25 的 softmin 三类分量在有效位置上的均值 | 不是硬分类像素比例；裁边／配准后的网格不直接对应原评分，全无效不填 0 |

历史字段 `high_risk_miss_rate_at_80` 实际存储上表的**高风险排除比例，越大越好**。
手算风险为 0,…,9：分数同序时唯一最高风险点被排除，结果 1；分数反序时该点被
保留，结果 0。真正的漏检比例是其补数。报告层改标签，不改历史字段或计算。

`alpha=0.05` 是 ROI 期望损失目标；C 的 `confidence_error=0.05` 是置信误差，
含义不同。流程 `accepted` 不意味着科学风险得到确认。
C 的 120 ROI 来自 12 个等额分层；空间分组策略不自动证明独立性。

源码依据：`src/trustsr/risk/local.py`、`src/trustsr/evaluation/score_diagnostics.py`、
`src/trustsr/evaluation/selective.py`；证据哈希见证据清单。

归一化反射率本身无量纲，但误差、AURC、LR 分数属于反射率尺度；三模型、K5、
邻域方差及 K5 阈值属于反射率平方尺度。覆盖、rho、softmin 分量无量纲。
校准选择满足 B risk_bound ≤ alpha 的最大已观测分数；没有可行候选时阈值为
负无穷、全拒绝。K5 固定阈值为 7.970395366024563e-6，不是风险目标 0.05。

部署调用与完整研究共享调用数、模型设置和 OpenSR 固定参数见
[正文 Methods](manuscript.md#3-methods)。OpenSR 的 HR 辅助协调不改变主 R1/R9。
